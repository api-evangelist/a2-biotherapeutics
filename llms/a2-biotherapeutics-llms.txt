# A2 Biotherapeutics

> A2 Biotherapeutics (A2 Bio) is a clinical-stage biotechnology company in Agoura Hills, California,
> founded in 2018 by Alexander Kamb, Michael Gallo and Paul Kang. It develops logic-gated cell
> therapies for solid tumors built on its proprietary Tmod™ platform, which uses a two-receptor
> activator/blocker design so a T cell attacks tumor cells that have lost an HLA allele while sparing
> normal cells that retain it. A2 Bio publishes no developer product API. This file describes the
> only live API surface it operates: the WordPress REST API of its corporate website, which also
> fronts two OAuth-gated Model Context Protocol servers.

  capability-gated, HTTP 401 anonymous.
